# Gerber_Web_Viewer（Gerber网页查看器）

This is a browser-based Gerber viewer. Simply open the `Gerber_Web_Viewer\Gerber_Web_Viewer.html` file and import a Gerber file to view board layer traces or a 3D model of the PCB. Please refer to `How_to_use.md` for detailed usage instructions. Additionally, the `Gerber_Web_Viewer\dist` directory contains all source files to support further development; details regarding customization and development can be found in `Development_Notes.md`.

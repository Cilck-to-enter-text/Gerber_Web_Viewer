# Gerber_Web_Viewer（Gerber网页查看器）
This is a browser-based Gerber viewer. Simply open the HTML file and import a Gerber file to view board layer traces or a 3D model of the PCB. For more details, please refer to How_to_use.md.

这是一个基于浏览器的Gerber查看器，点击html文件然后导入Geber文件即可查看板层走线或PCB的3D模型，更详细信息请查看How_to_use.md

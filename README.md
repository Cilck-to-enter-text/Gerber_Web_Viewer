# Gerber_Web_Viewer（Gerber网页查看器）

This is a browser-based Gerber viewer. Simply open the HTML file and import a Gerber file to view board layer traces or a 3D model of the PCB. Please refer to `How_to_use.md` for detailed usage instructions. Additionally, the `Gerber_Web_Viewer\dist` directory contains all source files to support further development; details regarding customization and development can be found in `Development_Notes.md`.


这是一个基于浏览器的Gerber查看器，点击html文件然后导入Geber文件即可查看板层走线或PCB的3D模型，更详细信息请查看How_to_use.md，同时在Gerber_Web_Viewer\dist目录下文件提供了所有的源文件支持二次开发，详细的二次开发内容在Development_Notes.md文件下
